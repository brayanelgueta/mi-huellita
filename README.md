# Mi Huellita — Carnet digital

Carnet digital para mascotas: perfil, vacunas, desparasitación, visitas veterinarias, peso y crecimiento, medicamentos y notas.

Es una sola página HTML, sin dependencias. Para usarla, abre `index.html` en el navegador. Los datos se guardan en el `localStorage` del navegador y se pueden exportar a JSON.
